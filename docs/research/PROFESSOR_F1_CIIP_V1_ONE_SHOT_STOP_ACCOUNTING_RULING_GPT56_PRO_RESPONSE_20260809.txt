ROOT_CAUSE

The failure is a deterministic caller-contract defect in the resource-metadata construction path.

execute_semantic_role constructs its pre-encoding resource object with:

Python
Run
"serialized_bytes": 0

It then passes that object to encode_container.

The encoder first canonicalizes the six frozen tables and computes:

Python
Run
total_size = METADATA_REGION_BYTES + sum(
    len(table_bytes[name]) for name in TABLE_NAMES
)

It then calls:

Python
Run
_set_computed(built["resource"], "serialized_bytes", total_size)

The existing _set_computed contract is:

Python
Run
if key in target and target[key] != value:
    raise ContainerValidationError(...)
target[key] = value

Consequently, the supplied zero is not interpreted as “unknown” or “unset.” It is interpreted as a caller assertion that the finished container has zero bytes. Since a valid container necessarily includes the fixed 1,048,576-byte metadata region, that assertion conflicts with the computed value and is correctly rejected.

The emitted closed-schema requirement and the encoder’s construction input are different lifecycle states:

Pre-finalization construction object: serialized_bytes is derived and may be absent.

Emitted container metadata: serialized_bytes is mandatory and must equal the exact finished byte count.

The code already embodies this two-stage model for other derived fields—table descriptors, table-directory commitment, partition commitment, and case-token digest—and the existing container test fixture already omits serialized_bytes before encoding. Its round-trip test verifies that the emitted field is inserted and equals len(encoded).

There is no length circularity. The metadata region has a frozen fixed size of 1,048,576 bytes, so after the table payloads are canonicalized the complete container length is known before the metadata region is encoded. The decimal width of the metadata value cannot alter the total container length.

The strict _set_computed behavior is therefore correct. The defect is the production caller’s premature placeholder, combined with missing regression coverage of that production resource-building path.

This STOP supplies no admissible scientific geometry result. Calculations may have occurred transiently before serialization, but no semantic container was emitted, decoded, independently rebuilt, committed, or validated. Those transient values cannot be cited as positive, negative, or partial CIIP evidence. That evidentiary consequence does not transform the accounting mistake into a mathematical or architectural failure.
