# Sherman QC F1 — multi-agent generality attack audit V2

Date: 2026-08-22

## Executive ruling

Three independent GPT-5.6 Sol/xhigh audits—architecture trajectory, scientific validity, and CAD-assisted production strategy—converged on the same conclusion:

1. No current version demonstrates unseen-family physical generalization. There is no GPI-A or GPI-B result.
2. The 70+ version sequence is cycling through recall birth, duplicate/perimeter false positives, deletion guards, and recall loss. Another numbered local certificate is unlikely to change the ceiling.
3. The immediate bottleneck is a trustworthy measuring instrument and physical evidence base, followed by event ownership/localization—not another candidate generator.
4. The fastest product-relevant lane is CAD event grouping plus scan-localized evidence, with the operator retaining disposition authority.
5. The highest-value sensing question is whether authentic organized range frames preserve evidence lost in fused PLY. Synthetic multiview data cannot answer that question.

## Three highest-value technical attacks

### 1. CAD event contraction plus scan-observed line localization

Contract adjacent/coaxial/tangent STEP primitives into one frozen CIBEC event before proposing a marker. Use the existing trusted transform, then localize one canonical line from observed two-sided scan turn evidence. Propagate registration uncertainty and abstain when the transverse confidence interval exceeds the matcher allowance. Never infer an unobserved CAD-only event.

This is the first attack because it uses current CAD+PLY assets, targets the measured CAD failure mode, and supports the production floor directly.

### 2. Scan-only event ownership and flat-face veto

Use the existing candidate pool only. Build a deterministic conflict graph over overlapping/parallel routes; crop to observed support; require positive two-sided normal-turn evidence; distinguish coplanar flanks, silhouette-only lines, rims, and junction fragments; select one representative per CIBEC event. Missing evidence must abstain, never reject.

This tests the repeated finding that many missed truth axes already exist in the pool and are lost during ownership/reconciliation.

### 3. Authentic organized-frame evidence adapter

For at least five morphologies with two captures each, acquire real organized depth/range frames, validity masks, intrinsics, extrinsics, timestamps, and calibration hashes plus matched fused PLY. Attach compact per-candidate per-view persistence, visibility, side-balance, and supported-span evidence. First use it only to validate/reassign existing candidates.

Require ≥50% reduction in same-object prediction-count variance, F1 gain ≥0.03, no visually lost unique fold, full replay, P95 ≤300 seconds, and RSS <16 GiB. A clean negative retires the raw-frame branch.
