# Pure contact-scorer V2 source gate

Prospective candidate finalized after independent source review; exact PRE and
source archive are still required before the one permitted execution. The fixed
denominator is 123 outcomes across 29 test functions (AST accounting, not yet
collection or passing evidence). Main has read the complete scorer and tests.

## Scope and decision

Qualify only the pure V13-result-byte/contact-carrier scoring bridge using
invented workflow-shaped JSON and straight lines. The generic11-case/6-family/
71-reference fixture is constructed in the test file, not read from Gold11.
The fixture is not evidence of an actual engine geometry fit. No metadata
decoding, raw input, native library, datum selection or pose estimation occurs.

Before execution, freeze the exact eight named source files in the harness,
final outcome count and this protocol; obtain independent PRE and archive exact
sources plus PRE. Main must read the complete candidate, tests and PRE first.
All frozen outcomes must pass with zero other dispositions, unchanged sources,
clean supervisor custody and independent POST. Any failure is terminal negative;
do not rerun or change a started attempt's candidate, limits or denominator.
The harness records the expected denominator; independent POST must verify the
actual pytest outcome count and every non-passing disposition from retained
output. Exit zero alone does not qualify this gate.

## Fixed prospective resources

One worker, numerical threads1,45CPU/55work/60monitored-parent seconds,
1GiB sampled process-group RSS and1MiB stdout. The tests exercise bounded small
invented JSON and line sets; this is not a128MiB or maximum-node capacity claim.
The JSON parser's node/depth validation follows decoding and cannot bound its
prior allocations. A later runner must separately enforce parsing/process
budgets on actual retained-result sizes. No binary/runtime attestation is claimed.

The exact hash-bound supervision function is reused from
`scripts/check_gold11_mesh_v4_custody.py`; its old main, source list and tests
are not called. Its process-group sampling, cleanup deadline and CPU footer
semantics remain unchanged. Source hashing and final receipt I/O are outside the
monitored supervision clock, not a hard real-time filesystem guarantee.

The fresh attempt retains STARTED.json, OUTPUT.txt and COMPLETED.json. Test
temporary files, if any, remain in the separately identified private cache.
No scientific case artifacts are expected. Independent POST checks the exact
three-file attempt namespace only after confirmed empty writer group. Output
overflow is a negative with a bounded retained prefix; a killed worker's missing
CPU footer remains unknown. Failed custody never permits favorable artifact
inspection or a positive result. No automatic retry or cleanup is provided.

## Unchanged comparison boundary

Preserve literal contact-sector carriers, assumed-mm original-scan frame,
sample-support endpoints, unknown physical event count/material side/calibration,
exact top-level/V2 eligible-instance projection, whole-case malformed handling
and explicit refused/no-carrier outcomes. Retain all references as FNs when
zero carriers are usable. The old matcher and aggregation functions, geometric
thresholds and undefined metrics remain unchanged.

A green source gate qualifies neither the connected engine nor the native-byte
workflow, complete physical runner/custody campaign, historical comparability,
offline accuracy targets or factory release. Those remain separate gates.
