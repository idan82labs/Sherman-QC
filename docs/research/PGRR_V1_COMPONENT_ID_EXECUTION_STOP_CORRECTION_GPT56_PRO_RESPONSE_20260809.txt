AUTHORIZED CORRECTION

V3 may change only these two functions and only with the stated semantics:

Select the lexicographically smallest complete 32-byte point ID among the component members and return its hexadecimal representation.

The producer may use:

Python
Run
local = int(np.argsort(ids, kind="stable")[0])

The independent validator may use:

Python
Run
local = min(
    range(len(indices)),
    key=lambda offset: bytes(ids[indices[offset]]),

This asymmetry is appropriate: it preserves independent implementations while requiring identical externally observable semantics.

Duplicate minima may resolve to different equal-valued member positions internally, but both implementations must return the same 64-character hexadecimal value. Empty membership must raise and produce no component ID; the implementations need not use the same exception class unless the existing locked contract already requires that.

No other production or validator change is authorized—not even refactoring, helper extraction, dtype conversion elsewhere, cleanup, exception normalization, performance optimization, or adjacent ordering changes.
