## Fixed numerical candidate

`backend/cad_guided_raw_extrema_index_v1.py` computes separately staged binary64
subtraction, three multiplications, then addition in the order((0+1)+2)+constant.
Each final numerical zero becomes positive zero. For a fixed direction, applying
the identical sequence to sign-selected AABB corners bounds the rounded program
on every member row by monotonicity. This is conditional on consistent binary64
round-to-nearest/gradual-underflow arithmetic and separate unfused operations;
sentinels are necessary checks, not binary attestation. It is not a real-valued
interval enclosure, legacy BLAS equivalence or physical uncertainty model.

The internal tree uses one stable sort on the longest root-box axis (coordinate
order breaks ties), leaves of256 actual raw IDs and bottom-up boxes. If
K=ceil(S/256), the implementation reserves2*2^ceil(log2(K)) node slots, including
unused slot zero and padded empty leaves. Each node carries its smallest raw ID.
The actual axis-extreme witnesses and smallest support ID initialize a query.
A node is skipped only when it cannot improve either value or smallest-raw-ID
tie; a box corner is never published as a raw-row witness. Every admitted row
remains eligible. Pruning quality does not affect correctness; worst-case work
can still exhaust the unchanged declared helper caps and refuse the whole batch.

Raw points and complete sorted support IDs are captured into immutable owned
buffers and hashed. Captured shape/dtype/byte counts and owned reconstruction
are validated. A late input, arithmetic, work or report failure clears every
projection and success binding; attempted work survives. Completed evaluated-row
and leaf counters advance only after successful evaluation. Coordinate work is
the declared6N+12S+S+6S+9E proxy, not a count of every array pass or CPU operation.

This standalone gate has one source buffer and one index per call. It does not
qualify a workflow registry: a future context adapter must share one immutable
raw buffer across whole/support indexes, enforce aggregate build/query/memory
budgets, retain exact support/cache identity and all family/slot denominators,
and clear the whole context on any failure. CAD projections, pose/refinement and
measurement admission are not modified here. Last-bit changes from legacy BLAS
can change exact pose deduplication, so connected equivalence is not assumed.
