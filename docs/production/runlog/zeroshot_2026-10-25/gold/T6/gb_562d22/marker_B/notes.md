# gb_562d22 marker B

Small spring-clip strip (6 mm wide), t ~1 mm. 3 bends.

| line | patches | what |
|---|---|---|
| B1 | 1-5 | leg 3/5 to middle 1/2 (~45 deg bend) |
| B2 | 1-8 | middle 1/2 to short web 7/8 (~118 deg bend) |
| B3 | 8-6 | web 7/8 to return leg 4/6 (~60 deg bend) |

B2 + B3 make a U-hook with a ~7 mm flat web (7/8) between them, so I marked 2 folds.
Doubts: if the adjudicator reads the hook as a single rolled radius, B2/B3 would merge into one; I think the flat web makes it two folds. The lines are short (5.5-5.9 mm = full strip width).
