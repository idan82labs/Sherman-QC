## Decisions, evidence and failure handling

Require every declared test to pass, no skip, worker exit0, no budget/supervision/
cleanup/custody error, an empty process group, identical before/after source map,
and the empty ARTIFACTS inventory. Independently audit the final result. Any
failure or unknown is terminal for this versioned attempt; preserve it and
document a new engineering reason/protocol/PRE before a successor. No ad hoc
reruns, cap changes or selective test removal.

Fresh `support_cover_v2_source-*` attempt directory retains STARTED.json,
OUTPUT.txt, ARTIFACT_INVENTORY.json, COMPLETED.json and empty ARTIFACTS. It is not
overwritten or cleaned up. Tests may use only pytest-owned invented temporary
files if explicitly reviewed; no scan/CAD/email/Gold/held-out reads are allowed.

Cover publication retains original member records on nonfatal paths, with all
failures/associations. A fatal outer exception or report overflow clears the
entire new output including nested evidence; no favorable prefix survives.
Publication checks are typed algebraic/schema consistency, not authenticity
against a hostile report author, a second geometry fit, propagated uncertainty
or proof of continuous support. Count, joint pose, physical event, material side,
calibration, datum and physical trim remain unknown/unverified.

Only a green independently audited source gate may support a separately frozen
connected comparison. Neither a source pass nor a protocol is roadmap completion.
