# Explicit-frame CAD corpus successor — 2026-09-30

This is a new terminal-attempt protocol, not a retry or edit of either completed
corpus run. It retains the V2 protocol's exact 20 unique STEP hashes/23 aliases,
source-root custody, sampled 60-second/4-GiB case caps, 1,230-second campaign,
source/artifact/log limits, claim-before-read, shared native admission,
exclusive execution and cleanup/no-retry rules. No mesh/scan/Gold/email access.
The source archive and independent PRE must bind this protocol and every new
extractor, adapter and pipeline source before the one execute.

## Engineering reason

Baseline V2-extractor/V5-unfold produced 6/20 flats and 16 folded displays.
The terminal V3-extractor/V6-unfold challenger produced 5/20 flats and 19 folded
displays. Its newly independent oracle caught a real angular-coordinate
regression on case05: recomputing a least-aligned-axis angular basis after
endpoint subtraction can choose a different basis when tiny direction
components are lost. Four marker locations differed by approximately 2.192 mm.
That result is retained and is not promotable. Other refusals and reduced
candidate counts remain in the denominator; their correctness is not assumed.

## Candidate and hypothesis

The first source freeze under this protocol was withdrawn before PRE approval
or any physical execution. An independent arbitrary-sector rotation test found
that exact-zero seam detection can conservatively refuse a valid wrapped domain
whose endpoint is1.11e-16 rather than0. The successor must recover a connected
circular arc from its largest complementary gap, verify arc span against the
union measure within the existing domain bound, and use those same boundaries
and midpoint. A new source/protocol archive, authored qualification and PRE are
required; the withdrawn attempt must never execute.

V4 extraction preserves the actual source angular frame, transports domains
and tangent rails as world radial vectors into a common carrier frame, and
constructs the marker in that same frame. It never quantizes an axis or selects
behavior by part identity. Independent synthetic fixtures cover near-coordinate
basis ties, arbitrary poses, translated origins and reversed frames.

The new stage-composition pipeline uses V4 extraction and adaptation with the
unchanged V6 selected-skin developer, V2 normalization/native oracle and exact
transport5/mechanism6 geometry contracts. Diagnostics identify extraction4 and
pipeline1 explicitly. No old result is relabelled; the native reader actually
re-extracts V4 features. Existing V6 source and both prior runs remain unchanged.
All full-material, seam, winding, hole, finite-strip and overlap gates persist.

Acceptance is source/native qualification plus full-case comparison: restore
the prior available geometry without any oracle failure, retain every negative
case, and inspect all available flat outputs. Candidate count changes are
reported, never scored as accuracy without independent references. The target
of at least90% extraction precision/recall remains UNSCORED. Availability,
agreement with a predecessor and a discrete flattening oracle are not truth.

Independent POST must record every row against both terminal predecessors,
including extraction count, folded/flat availability, exact refusal and oracle
evidence. Public Site/default runtime promotion and manufacturing readiness are
not authorized by this direct-engine diagnostic. Subsequent broader trim or
stepped-wall support needs a separate source freeze and review, not a relaxed
gate or guessed flat surface in this run.
