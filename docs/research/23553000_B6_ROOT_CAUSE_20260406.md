## Interpretation
- This is not a scan-completeness issue.
- This is not a merge-selection issue.
- This is not a global-assignment issue anymore.

The local evidence is internally biased:
- one surface side is materially underrepresented (`423` vs `176`)
- both classified point sets are individually close to the expected CAD normals
- but their fitted normals produce an included angle of `68.58°`, which becomes a bend angle of `111.42°`
- the signed plane offsets are large and opposite in sign (`+4.505 mm`, `-4.732 mm`)

That combination strongly suggests local surface segmentation / side sampling contamination near this short wing bend.

## Practical Conclusion
- `CAD_B6` should not be “fixed” by more merge heuristics.
- The next valid patch class is a local-measurement patch for short obtuse bends, for example:
  - reject or down-rank surface-classification candidates when opposite signed plane offsets are too large
  - build a more constrained bend-side strip for the short wing region
  - or prefer a new short-wing-specific local estimator if it beats the current `111.42°`
