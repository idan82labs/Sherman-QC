## Why fewer rows did not pay

V1 construction costs 819,200 common steps per population. V2 adds 2,008,832
primitive leaf steps, 9,525 merge steps and 106,964 construction packing steps,
plus 194 chooser steps for the first three populations or 1,198 for folded.
Thus V2 starts at 2,944,715 or 2,945,719 before any query. Every active bound
call costs 390 primitive +22 packing steps, versus the old 37-step world
supplement. This matches candidate `_build_shear` lines 143–189, `_box` 128–137
and `_node_bounds` 191–204; `_extra` 61–68 charges the shared cumulative budget.

- **Flat:** queries 1–4 and 8–9 each still evaluate all 128 leaves in both arms;
  their intervals are respectively exact zero or an exact translated constant.
  The two near-normal queries 10–11 improve 128 → 2 leaves each. Overall row work
  falls 23.31%, but query-only common work rises 2,576,822 → 2,677,592, even before
  construction. The source's conservative rounded-program enclosure can
  straddle an exactly attained endpoint; exact planarity does not imply safe
  pruning of its rounded result. No per-node bound-width trace was retained,
  so that mechanism is a source-supported explanation, not a measured width.
- **Resolved:** eight normal/near-normal queries improve 128 → 2 leaves each;
  total leaves 1084 → 76 and evaluated rows fall 92.97%. Query-only common work
  falls 2,583,512 → 495,248, saving 2,088,264. Added construction is 2,125,515:
  the complete batch still loses 37,251 steps. CPU also worsens 7.35×. It would
  be incorrect to discard construction or extend the query horizon afterward
  and declare this selected near-win a pass.
- **Plateau:** leaves 1082 → 1082 and node-bound calls 2306 → 2306. There is no
  evaluated-row saving. Query bound/packing work 950,072 replaces 85,322 old
  corner steps. Equal extrema and original-ID tie obligations remain real;
  candidate pruning at lines 222–225 correctly cannot assume a geometric
  plateau certifies identical rounded values or the minimum raw witness.
- **Folded:** first eleven queries have identical leaf counts across arms;
  only query 12 improves 24 → 9. Overall leaves 166 → 151, bound calls 946 → 908,
  rows fall 9.02%. Query-only work nevertheless rises 418,222 → 722,756:
  34,560 saved leaf-arithmetic steps are outweighed by 339,094 extra bound
  steps. Another 2,126,519 construction steps creates the full 2,431,053 loss.
  A nonzero global seed shear was built (128 leaves/127 merges); this was
  not a zero-shear bypass. Its actual chosen axes/slopes were not included in
  these metric records, so their orientation must not be invented.

The large CPU penalty is consistent with numerous scalar primitive/boxing/
callback operations replacing cheap vectorized leaf work; aggregate timings
do not isolate those functions as a profiler would. Packed retained payload
adds only 12,288B including metadata, and both recorded payload peaks are
3,211,264B. This experiment failed cost efficacy, not its memory or CPU cap.

## Cheapest justified direction, not another gate until it passes

Keep the unchanged V1 path and retain this negative experiment. The narrowest
useful design direction is **avoid optional work before trying the cheap world
certificate**: world-first rejection, with any expensive extra certificate
built lazily/reused only on unresolved work, rather than eagerly decorating
every node. That is an unimplemented cost-avoidance hypothesis, not evidence
it can meet the frozen rule; it must retain exact leaves, lineage, minimum-ID
ties and every added-work charge. Merely vectorizing the present V2 might help
CPU but cannot erase the demonstrated abstract construction deficit.

Do not jump from this result to a costly new global reorder. For a proposed
Morton construction allowance 80S, S=32,768 gives 2,621,440 additional steps.
The folded V1's *entire* twelve-query common work is only 418,222. Even removing
all that query work could not amortize an additive 80S build on this fixed
batch. This is a source-cost bound, not an executed Morton result or a claim
about implementations that replace, rather than add to, existing costs.

No new experiment, altered threshold, longer horizon, easier population or
physical rerun is selected here. These four fixtures are now consumed
development evidence; future mechanism choices informed by them are not
independent confirmation. No inference about the actual physical failures'
query orientations follows from this synthetic matrix.
