## The product contract to build toward

Keep these independent for each job:

| Field | Meaning / required behavior |
| --- | --- |
| Execution status | Queued, running, complete, failed, cancelled; a completed computation is not a passed part. |
| Inspection validity | Valid, insufficient capture, untrusted registration, or unsupported input; invalidity requests rescan/review, not rejection of the part. |
| Expected event | Versioned CAD component, finite forming axis/span, adjacent surfaces and event identity; never an observed-state label. |
| Observed state | Versioned stage-aware taxonomy: formed, explicitly observed unformed, partially formed where applicable, or unknown. Partial formation must not be silently collapsed; absence of visible support stays unknown. |
| Conformance | Measured angle/location/radius where observable, uncertainty and tolerance result; unknown when evidence is insufficient. |
| Display evidence | Coordinate frame, units, support region, finite admissible marker and provenance. A count estimate is not a localized observation. |
| Qualification | Exact candidate/model/config/evidence bundle, approved use and operator authority; research-only unless explicitly released. |

An operator should see which observations support a conclusion, which areas were
not inspected, and whether to rescan or review. AI may explain measured evidence;
it must not invent measurements, fill unseen bends, or decide release authority.
