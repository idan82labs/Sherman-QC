## Connected source-audit refinements

Independent `/root/cad_support_lineage` and root inspected the exact V7 closure
loop. The 20M counter sums every core's base and halo cardinalities plus every
distinct closure's cardinality; it is not a profile of graph computation.
SHA-bucket plus exact-array closure deduplication occurs BEFORE charging the
new closure, constructing its raw-row union and fitting it
(`backend/cad_guided_noisy_mesh_planes_v7.py:271,307,315`). An exact eligible-mask
component cache could save repeated graph construction, but must reproduce the
old membership-cap refusal if that policy is unchanged.

With T triangles, two complete partitions and shared-edge manifold degree at
most3, core base-plus-halo cardinality lies between4T and10T. At most16 distinct
closures add at most16T: an admitted2M-triangle input therefore has a
conservative upper bound of52M logical memberships. This is a capacity bound,
not an observation of the failed case's overlap. Input-size admission and20M
membership admission are not mutually sufficient. A compressed successor must
separately retain expanded logical cardinality, unique stored bytes, reference
bytes, hashing/comparison/decoding work and peak materialization. Admitting more
than20M logical memberships would be a NEW policy, not a disguised cache fix.

native whole-solid gate into its consumers. Global validation happens before
cylindrical inventory (`backend/cad_guided_native_features_v1.py:361`). Local
analytic geometry and complete trimmed-face inclusion can in principle survive
an unrelated global defect, but material side does not follow from that. A
globally reversed shell preserves surface positions and unsigned tangency while
reversing cylinder polarity and signed flange interpretation. The existing
measurement/publication contract explicitly requires an inner surface; bypassing
whole-solid validation or relabeling neutral geometry would violate that premise.
