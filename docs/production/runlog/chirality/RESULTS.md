**The 14 residual PASSes.** They are 4 G1 parts at STAGE_1: HT-003, LB-003, PN-003, TD-003. Each scan has x, y and z mirrors, and PN-003 and TD-003 also OX. Each has 1 PASS, a bend-line position.
- The check confirmed the **proper** image on every hypothesis. Each of these stages is one flat panel pair with one bend.
- Every panel is individually its own mirror image: a flat plate with holes flips over.
- E3's articulated fit places each panel independently. Probes carried by per-panel poses therefore see the proper image on every panel, and the chirality is in the panels' *relative* pose: the bend folds the other way.
- **Design gap.** Per-panel probe placement cannot see configuration-only chirality. A fix would be:
  - also carry the probes with the datum pose and require that each panel's fitted pose agree with the decoded stage's nominal relative pose; or
  - treat a stage whose chirality is configuration-only as unverifiable, and withhold.
- Neither was implemented after the freeze. They are the same G1 cases the live engine and the earlier prototype missed.

**Main real-data cost: CHIRALITY_STAGE_UNMAPPED.**
- When E3 cannot name an exact compiled stage (decoded stage `None`: partial or inexact decodes, typical of real in-process scans), the candidate has no map entry.
- For a chiral part it then withholds every PASS, by design.
- This causes 7 of the 8 A1 withholds and 3 of the 5 held-out withholds.
- Mapping the out-of-order and inexact formed sets is the main lever for real-data coverage. E1's `stage_points_from_compiled` can build any formed set, so the map could be computed per decoded set at runtime (~1–10 s) or for every set at compile.

**G1 gate on the candidate** (official E4 scorer, same tier and compiles as live):
- FALSE_PASS 0 / 553 and WRONG_OR_MIRRORED_NEVER_PASS 0 / 32, the same as live.
- Every accuracy, calibration and state gate passes.
- DECISIVENESS 0.941 vs live 0.984; the gate is ≥ 0.9.
- Median U 0.110 mm / 0.121° vs live 0.106 / 0.116, from the PASS → REVIEW withholds.

**Runtime.** The check adds < 1 s per pass.

- Real: P50 24.3 vs 24.4 s.
- Map compute, compile side: 0.2–12 s per stage, at most 3.6 min per part (38172000, 13 stages).

## 3. Decisions for the owner

1. **Do not release C as is.** P1 fails (14 / 252) through the configuration-only gap, and P2a fails (3 / 234) through the live rule on occluded scans. Both need a design change and a new frozen evaluation.
2. **Fix the two gaps before a re-run:**
   - (a) **Configuration chirality.** Check probes under the datum pose too, or declare such stages unverifiable.
   - (b) **Unmapped decoded stages.** Map any formed set.
   - Optionally (c): should the live `MIRROR_FITS_BETTER` rule defer to the feature check on chiral parts, when the features confirm the proper image?
3. **Coverage cost to accept.** On real seen data, 16 / 88 genuine natives would lose all PASSes (REVIEW), mostly via (b). It is 3 / 91 on clean synthetic scans.
4. **Contract amendment A3 and re-pin plan.** These are in DESIGN.md §5; there is no change until 1 and 2 are settled.
