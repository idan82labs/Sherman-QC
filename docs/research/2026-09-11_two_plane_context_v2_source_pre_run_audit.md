This closes the known historical test-initializer omission prospectively; it
does not retroactively attest old incomplete closures. The inert package avoids

standard library and OS binaries are explicitly outside repository hashes.

The new harness reads each source with O_NOFOLLOW, regular-file/type checks,
a 2 MiB byte cap and stable descriptor/path identity before and after. It
authenticates the exact supervisor bytes before compiling only its definitions;
the old supervisor main, source selector and old tests are never called.
No recursive corpus discovery, environment policy override, test subset,
physical decoder, native reader or old benchmark runner is permitted.

The worker uses `-I -S -B -u`, a fresh inert backend, disabled plugin autoload,
`-c /dev/null --noconftest -p no:cacheprovider`, and one numerical thread per
library. The supervisor creates one dedicated process group, rejects unexpected
descendants, samples group RSS, bounds stdout and monitors work/cleanup time.
On failure it must terminate only its owned group and report confirmed emptiness
or an explicit custody failure. An unknown group cannot become a positive.

Fixed caps are **45 worker CPU seconds, 55 monitored work seconds, 60 monitored
parent/cleanup seconds, 1 GiB sampled process-group RSS and 1 MiB retained output**.
The underlying helper's logical/payload work caps are separate from process RSS.
These limits are proportionate planning guards given the bounded small fixtures
and prior 69-outcome integration's approximately 6.64 CPU seconds, not a proof
that this new gate will finish under its cap. Source reads/setup/final receipt I/O
are outside the monitored clocks; memory sampling is not a hard instantaneous
allocation ceiling. No cap may be raised after launch.
